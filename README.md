# ProxyPulse CLI

Быстрый кроссплатформенный (Windows / macOS / Linux) асинхронный парсер и чекер публичных прокси
на Python 3.11+ с красивым консольным интерфейсом на `rich`.

- Качает свежие списки `HTTP`, `SOCKS4`, `SOCKS5` из открытых репозиториев GitHub и убирает дубли.
- Проверяет прокси сотнями параллельных соединений, показывает живой прогресс-бар.
- Сортирует рабочие прокси от самых быстрых к самым медленным и определяет страну.
- Сохраняет результаты в `results/ДАТА_ВРЕМЯ_режим/` и может сразу открыть папку.

## Быстрый старт

### Windows
Дважды кликните `start.bat`. При первом запуске скрипт сам создаст виртуальное окружение `.venv`
и установит зависимости.

### macOS / Linux
```bash
chmod +x start.sh   # один раз, если нужно
./start.sh
```

### Вручную
```bash
python -m venv .venv
# Windows:      .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Требуется **Python 3.11 или новее**.

## Меню

| № | Действие |
|---|----------|
| 1 | Спарсить и сразу проверить прокси: выбор типа (`HTTP`, `SOCKS4`, `SOCKS5` или все сразу), таймаут (по умолчанию 5 сек), потоки (по умолчанию 250) |
| 2 | Проверить свой `.txt` файл (`ip:port` или `user:pass@ip:port`) и выбрать тип прокси |
| 3 | Только спарсить свежие списки без проверки |
| 0 | Выход |

Потоки настраиваются в диапазоне **50–500**, таймаут — **1–60** сек (значения вне диапазона автоматически
приводятся к допустимым). `Ctrl+C` во время проверки останавливает её и гарантированно сохраняет уже найденные прокси (список результатов передаётся чекеру по ссылке и переживает прерывание).

## Как проверяются прокси

Проверка идёт цепочкой, каждая следующая проба выполняется только если предыдущая не удалась:

1. `http://api.country.is/` — быстрый GeoIP без лимита 45 запросов в минуту; ответ `{"ip": "...", "country": "US"}`.
2. `http://icanhazip.com` — тело ответа должно быть корректным IP-адресом.
3. `http://httpbin.org/ip` — JSON с полем `origin`.

Переход к следующей пробе — при **любой** ошибке, таймауте, не-`200` или непригодном ответе, поэтому живой прокси
не отбраковывается из-за недоступности одного сервиса. Валиден прокси, получивший HTTP `200` и корректный ответ
хотя бы одной пробы. Код страны определяется по `api.country.is`; если сработал резервный запрос — `??`.
Отклик измеряется в миллисекундах по успешному запросу, валидные сортируются по возрастанию пинга.
На все пробы одного прокси действует общий потолок ≈ 2×таймаут.

Технические детали: параллелизм ограничен `asyncio.Semaphore`, общий `TCPConnector(limit=0, ssl=False)`;
HTTP-прокси проверяются штатным механизмом `proxy=` в `aiohttp`, SOCKS4/SOCKS5 — через
`aiohttp_socks.ProxyConnector`.

## Формат результатов

Для каждого типа с найденными валидными прокси создаются два файла:

- `valid_<type>.txt` — чистый список `ip:port` (для загрузки в любой софт);
- `detailed_<type>.txt` — расширенный список: `ip:port | 142ms | DE`.

В режиме 3 (только парсинг) создаются файлы `scraped_<type>.txt`.

## Источники

`TheSpeedX/PROXY-List`, `monosans/proxy-list`, `proxifly/free-proxy-list`, `vakhov/fresh-proxy-list`,
`hookzof/socks5_list`. Если какой-то источник временно недоступен или поменял адрес файла, он помечается
в таблице как «недоступен», а работа продолжается с остальными. Список источников — константа `SOURCES`
в `core/scraper.py`.

## Частые вопросы

- **Не открывается окно выбора файла (Linux).** Установите Tk: `sudo apt install python3-tk`.
  Без графической среды программа предложит ввести путь к файлу в консоли.
- **Ошибка SSL при скачивании списков на macOS.** Выполните `Install Certificates.command`
  из папки установленного Python или установите пакет `certifi` (`pip install certifi`) — он подхватится автоматически.
- **Мало валидных прокси.** Это нормально: бесплатные публичные прокси быстро «умирают».
  Для больших списков увеличьте таймаут до 8–10 сек.
- **Скорость.** Чем больше потоков и короче таймаут, тем быстрее проверка, но слишком агрессивные
  значения могут перегрузить ваш роутер или канал.

## Важно

Используйте программу только законно и в соответствии с правилами вашего провайдера и сервисов,
к которым вы обращаетесь. Публичные прокси небезопасны: не передавайте через них пароли и личные данные.
